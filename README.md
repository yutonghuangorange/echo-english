# Echo · 配音与唱歌练习

把喜欢的 YouTube 对白和歌曲，变成自己的声音。支持英语、中文、日语、韩语等原文字幕的逐句配音、跟读、伴奏录唱与回听。普通配音无需后端或 API Key；可选的去原唱伴奏、电影背景音提取共用同一个本机服务。

## 所需配置

**不需要独立显卡。** 插件的字幕、配音、录音、回听和导出在 Chrome 中运行；本机伴奏／背景音分离支持 CPU，以及安装 CUDA 版 PyTorch 后的 NVIDIA GPU 加速。Apple 芯片 Mac 支持 MPS 加速，自动检测可用性，失败可回退 CPU；实际加速幅度仍需在可用 GPU 上实测。

| 项目 | 仅使用插件：字幕、配音、录音、回听 | 额外提取伴奏／电影背景音 |
| --- | --- | --- |
| 电脑 | 能流畅播放 YouTube 的电脑，无需独立显卡 | 多核 CPU，使用两个 CPU 线程；NVIDIA CUDA / Apple MPS 加速可选；本机已验证 RTX 3060 Laptop 6 GB |
| 内存 | 建议整机 8 GB 或以上 | 建议整机 8 GB 起步，16 GB 更宽裕，尤其同时打开多个浏览器标签页时 |
| 磁盘 | 按录音数量预留空间；无损录音和合成文件更大 | 建议至少预留 5 GB，供 Python 环境、工具、模型、处理中间文件与伴奏缓存使用；长期录音需另留空间 |
| 系统 | Windows / macOS / Linux 上的新版桌面 Chrome | Linux x86_64、macOS Intel / Apple 芯片、Windows x64；macOS 15 双架构自动验证通过；Windows 待实机验证 |
| 软件 | 仅需 Chrome，不需要 Python、Node.js 或 API Key | Python 3.10–3.12、FFmpeg（含 ffprobe）、Node.js 22+ 或 Deno；安装方式见下方 |
| 音频设备 | 录音需要麦克风及浏览器、系统权限；建议戴耳机 | 同左；戴耳机可减少伴奏被麦克风收进去 |
| 网络 | 观看 YouTube、读取在线字幕及查词需要联网；已缓存录音可本地回听 | 首次安装、首次下载模型及提取 YouTube 音频需要联网；已有伴奏可直接回听和录唱 |

内存与磁盘数值是建议起点，**不是实测最低配置**。长录音、无损格式和整首合成会增加资源占用。录音保存在浏览器，伴奏在浏览器与本机服务各有缓存；插件的缓存管理只清理浏览器副本，本机服务缓存位置见下方说明。

伴奏生成不是实时处理。已有 Linux CPU 测量：i7-1165G7 / 16 GB 内存，15 秒音乐片段约处理 35 秒，分离进程内存峰值约 1.5 GiB。另一次同素材对比：i7-11800H 处理约 20 秒电影片段需 30.89 秒，RTX 3060 Laptop 需 5.06 秒（均含载入和写出，不含下载）。短片段结果不代表整首歌曲或其他电脑的速度；当前单次最长 10 分钟。默认安装 CPU 依赖，GPU 需额外安装，步骤见 [CUDA 加速](karaoke/README.md#可选nvidia-gpu-加速)。

各系统安装与验证状态见 [跨平台适配](PLATFORM_SUPPORT.md)，伴奏依赖与缓存位置见 [伴奏安装与使用](karaoke/README.md)。

## 安装

从 GitHub 仓库选择 **Code → Download ZIP** 并解压，或使用 Git 克隆仓库。加载时选择解压目录中的 `extension/` 文件夹，不是整个仓库。

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择本项目下的 `extension` 文件夹。
4. 打开或刷新一个 YouTube 视频播放页，点击工具栏的 Echo 插件图标打开面板（可先在扩展程序菜单里固定图标）。

修改代码后，在扩展程序页面点重新加载，再刷新 YouTube 页面。

### 可选：一键安装并启动伴奏服务

普通配音、跟读、录音和回放只需要 Echo 扩展。「生成伴奏」或「提取背景音」还需要在运行 Chrome 的同一台电脑上启动本机服务；安装扩展不会自动安装这些依赖。

打开终端，进入解压或克隆后的项目根目录，运行：

```bash
bash start-karaoke.sh
```

首次会检查 Python 3.10–3.12、FFmpeg 和 JS 运行时，创建项目独立环境并安装依赖，然后启动服务。以后仍运行同一命令，会复用已安装环境；安装失败后可修复错误并重新运行。首次安装需联网，依赖可能占约 1–2 GB；约 80 MB 的分离模型在首次生成伴奏时下载。

- **Linux x86_64**：支持；缺少系统组件时通过 apt 安装，可能要求管理员密码。其他发行版需自行配置 Python / FFmpeg。
- **macOS Intel / Apple 芯片**：已提供脚本安装路径，尚待实机验证；缺少系统组件时需要已安装 Homebrew。
- **Windows x64**：已提供 PowerShell 安装启动入口，尚待实机验证。先安装 x64 Python 3.10–3.12、FFmpeg 和 Node.js 22+ 或 Deno，再运行下方命令。

保持终端开启，按 `Ctrl+C` 停止。回到插件切换「唱歌曲 · 伴奏监听」，查看服务状态；已打开面板时可点击「重新检测」。连接成功后生成伴奏，再试听和录唱。未连接时会展开启动说明。服务只监听 `127.0.0.1:8765`；已有的浏览器伴奏缓存和录音回放不要求服务在线。

Windows 在 PowerShell 中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-karaoke.ps1
```

两个脚本均可从任意目录调用完整路径，自动创建本机专用 `.venv`；不要跨机器复制虚拟环境。Intel Mac 自动选择 PyTorch 2.2.2，其他目标平台使用 2.5.1。

完整配置见 [伴奏安装与使用](karaoke/README.md)；实机验证步骤与当地 agent 交接见 [跨平台适配](PLATFORM_SUPPORT.md)。

## 使用

配音和唱歌均支持三种录音范围：整段视频（唱歌时为整首歌曲）、当前片段、段落（多句）。范围选择直接显示在练习主区，听原声、录音、循环和自动练习共用所选范围。整段与段落最长 10 分钟；段落需要至少两句时间轴字幕，连续录下选定多句及句间空隙。整段和段落不自动跳下一句，片段模式可以开启。配音与唱歌按视频分别记住范围选择；旧版配音练习继续使用当前片段。

「当前片段」可通过主区的下拉框直接选句，自动更新起止时间；修改时间后显示为自定义范围。配音模式也支持下拉选句。歌词卡片上的「调整语言」跳到台词／歌词页并展开语言与字幕设置。

配音和唱歌共用底部的「听原声 / 回听 / 录音」主操作，按钮按模式调整名称。歌词准备统一在台词／歌词页读取或导入；没有字幕时，练习页提供「准备字幕」快捷入口。录音页集中管理版本、回放、下载与合成；所选版本的删除位于录音卡片上，列表快捷删除和撤销保留。

顶部按活动切换「说对白 · 配音跟读」和「唱歌曲 · 伴奏监听」。说对白适用于访谈、影视、动漫等，直接录制麦克风；唱歌曲复用本机伴奏生成和混音录唱。切回说对白或切换视频会关闭伴奏。内容语言在「台词 / 歌词 → 语言与字幕显示」中选择，默认根据文本建议，可手动更正。

1. 在面板底部搜索视频，或直接打开喜欢的视频。优先选择带目标语言字幕或时间轴歌词的视频。
2. 点击「读取台词」，插件会尝试展开视频简介、打开文字记录，并等待台词加载；也可以导入 SRT / VTT 字幕。
3. 选择一句台词，或在视频播放时标记起点、终点。每段最多 10 分钟，可选 0.75×、1×、1.25×。
4. 点击「听原声」，再点击「开始配音」，首次使用需允许麦克风权限。
5. 配音时视频静音并继续播放，到终点自动停止，也可手动停止。
6. 点击「我的配音 + 画面」随视频回放，或点击「原声 / 配音」依次听两种版本。
7. 可隐藏台词练习脱稿，也可下载 WebM 录音。

下载文件按「视频标题＋片段起止时间＋音频类型」命名，例如 `晴天_00m50.0s-01m05.0s_人声.webm`。人声＋伴奏及整首合成 WAV 使用同一命名规则，整首文件另标「整首合成」。保留各语言标题，自动替换文件名不支持的字符；标题无法读取时回退到视频 ID。

唱歌的录唱范围支持「整首歌曲 / 当前片段 / 段落（多句）」。段落模式需要至少两句时间轴歌词，通过起句和止句选择连续多句，连同句间间隔一次录下；听原曲、伴奏生成、前置播放、循环和自动练习均沿用该范围，选择按视频保存。段落可与单句录音混合合成整首：按原视频时间轴放置，重叠处默认采用最新录音，未录处保留空白，不压缩时间。在「录音 → 分段合成整首 → 选择片段并合成」打开独立拼接界面，逐段试听、勾选是否导出、切换其他版本，并试听整首。试听与下载使用同一份选择、内容类型及打开界面时的回听音量比例；修改选择会停止旧试听。选择按视频保存在本地，恢复自动选择可重新采用最新版本。合成整首仍需 1× 录唱；混合下载需覆盖整首的伴奏。

片段的「前置播放」可在「练习 → 准备与自动练习」选择关闭（默认）、前 N 秒（0–30，初始 3 秒）或上一句，按视频保存。选择上一句时从上一句开头播放到当前片段起点，需要时间轴字幕；没有上一句则直接开始。例如片段为 50–60 秒，设为 3 后先听 47–50 秒原声，再开始片段录音；录音与下载仍为 50–60 秒。前置播放开始时即进入录音布局并显示麦克风实时音量，状态栏提示准备倒计时；到片段起点才正式录音，准备期间可点击「取消准备」，不保存录音。前置播放按视频时间计算，慢速时实际准备更久；起点不足时从视频开头播放。听原声、循环和自动练习也应用此设置，回听与原声对比保持录音范围。

「速度与麦克风」中的「录音音质」可选高品质压缩（默认，Opus 编码目标 256 kbps）或无损 PCM，选择在本机记忆，配音和唱歌共用，仅影响新录音。无损通过 Chrome 原生 PCM 录制，不经过 Opus；原始文件仍为 WebM，体积明显更大，部分外部播放器可能不支持。当前浏览器不支持 PCM 时会提示改选高品质压缩，不会自动降级。无损指编码阶段不压缩，麦克风、系统音效、回声消除、自动增益和手动增益仍会影响声音。

「录音 → 下载与录音详情」显示该条新录音的实际格式、压缩编码目标码率、麦克风及编码输入的采样率和声道数，以及浏览器报告的回声消除、降噪和自动增益状态；未报告的状态标为未知。旧录音没有这些参数。PCM 不显示浏览器返回的默认压缩码率。现有混合、整首合成 WAV 仍为 44.1 kHz / 16 位双声道，经过混音和格式转换，不承诺与原始 PCM 逐样本相同；旧 Opus 录音转成 WAV 也不能恢复已丢失的细节。

在「练习 → 速度与麦克风」可分别开关回声消除和自动增益，两项均为配音默认开启、唱歌默认关闭，按模式分别记住选择。外放时可尝试回声消除；人声偏小时可尝试自动增益，但唱歌可能出现音量起伏。调整从下次录音生效，实际处理效果取决于浏览器和设备；唱歌始终关闭降噪。关闭自动增益时可调整「手动录音增益」（0–24 dB，默认 0），固定放大新录音，回听与下载均生效，按模式记忆；建议从 +6 dB 开始，留意过载提示。手动增益不叠加到自动增益上，也会放大背景噪声，旧录音不受影响。

回放使用**录制时**的起止点与速度，不受之后选中的字幕片段影响。每句保留最近 3 次录音；第 4 次会替换该句最早的一次。展开「录音 → 录音版本」可选择旧版本、下载或删除，并可撤销最近一次删除。

### 可选：电影配音保留背景音

在「说对白 · 配音跟读」中，选择当前片段、段落或整段视频，主动勾选 **「保留背景音（电影配音，可选）」**。该选项默认关闭，按视频记住选择；与唱歌的伴奏开关分别保存。

开启后显示「背景音设置」，使用同一套本机 Demucs 服务提取背景音：先点「提取片段／段落／整段背景音」，试听并调整监听音量，再从原来的主按钮开始配音。勾选本身不会开始分离或打开麦克风。最长 10 分钟，建议先试短片段；可能残留原对白，也可能损失部分音乐、环境音和音效，暂不支持只去掉一个角色。

录制时只保存麦克风人声；回听可单独开关背景音，并分别调整人声和背景音量。「录音 → 下载与录音详情」可下载原始人声或「人声＋背景音」WAV，混合导出暂支持 1× 录音。关闭该选项后恢复普通配音，无需运行本机服务；已有带背景音录音仍可在回听区单独控制。电影背景音与歌曲伴奏共用提取、缓存、取消、同步播放和混合导出代码，不需要另外安装服务或模型。BandIt 仍为独立实验，尚无模型选择入口。

## 数据与权限

- 仅在 `https://www.youtube.com/*` 注入内容脚本，没有全站读取权限。点词查询使用 Free Dictionary API。
- 麦克风由浏览器按需授权。停止录音后释放麦克风。
- 录音存入 YouTube 页面来源下的 IndexedDB，没有音频上传接口。清理网站数据可能删除录音；它不是扩展独立的私密存储空间。
- 此版本未复制第三方项目代码。架构参考方向来自 DeepHear 与 Shadowing Space。

## 当前限制

- 原型仅支持普通 `/watch?v=...` 视频，暂不支持直播、Shorts、广告中录制。
- 文字记录只读取当前 DOM 已加载的行，不保证完整；YouTube 改版可能影响读取。末句终点可能估算，需手动调整。导入完整字幕更可靠。
- 录音与视频通过两个媒体元素协调播放，尚非逐帧同步。首次播放、卡顿及手动拖动 YouTube 进度条可能引入偏差；练习中请使用面板的停止按钮，避免直接操作播放器。
- 普通配音静音整条视频音轨；可选的本机去原唱功能见 [伴奏安装与使用](karaoke/README.md)。
- 下载的是独立音频，不是合成视频；没有发音评分或云同步；录音版本与历史保存在本机浏览器中。
- 已完成字幕解析自动测试与 JavaScript 语法检查；尚未完成真实 Chrome / YouTube / 麦克风端到端测试。

## 验证

模块职责与媒体流程约定见 [代码结构说明](ARCHITECTURE.md)。开发测试使用 `npm ci` 后运行 `npm test`；fake-indexeddb 仅用于测试数据库迁移、版本保留、删除恢复和会话存储。插件依旧无需安装依赖或构建，直接加载 `extension/`。

运行：

```sh
node --test tests/*.test.cjs
node --check extension/content.js
node --check extension/background.js
```

真实浏览器验收：

- 授权 / 拒绝麦克风，取消授权等待后重试。
- 设置 5 秒片段，听原声、配音、自动停止、回放、依次对比。
- 在慢速下配音并回放，确认画面和音频节奏。
- 播放 / 录音时点击停止、关闭面板、切换视频，确认麦克风释放和静音状态恢复。
- 刷新页面恢复最近录音，下载文件确认可播放。
- 分别导入 SRT / VTT，验证多行台词、跳转、隐藏台词。
