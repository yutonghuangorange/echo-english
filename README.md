# Echo · 英语配音练习

一个无需后端、无需 API Key 的 Chrome Manifest V3 插件原型，在 YouTube 播放页面练习英语配音。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择本项目下的 `extension` 文件夹。
4. 打开或刷新一个 YouTube 视频播放页，点击工具栏的 Echo 插件图标打开面板（可先在扩展程序菜单里固定图标）。

修改代码后，在扩展程序页面点重新加载，再刷新 YouTube 页面。

## 使用

1. 在面板底部搜索视频，或直接打开喜欢的视频。优先选择带英文字幕的短视频。
2. 点击「读取台词」，插件会尝试展开视频简介、打开文字记录，并等待台词加载；也可以导入 SRT / VTT 字幕。
3. 选择一句台词，或在视频播放时标记起点、终点。每段最多 120 秒，可选 0.75×、1×、1.25×。
4. 点击「听原声」，再点击「开始配音」，首次使用需允许麦克风权限。
5. 配音时视频静音并继续播放，到终点自动停止，也可手动停止。
6. 点击「我的配音 + 画面」随视频回放，或点击「原声 / 配音」依次听两种版本。
7. 可隐藏台词练习脱稿，也可下载 WebM 录音。

回放使用**录制时**的起止点与速度，不受之后选中的字幕片段影响。每个视频仅保存最近一次录音；重录会覆盖。请下载保留需要的版本。

## 数据与权限

- 仅在 `https://www.youtube.com/*` 注入内容脚本，没有全站读取权限。点词查询使用 Free Dictionary API。
- 麦克风由浏览器按需授权。停止录音后释放麦克风。
- 录音存入 YouTube 页面来源下的 IndexedDB，没有音频上传接口。清理网站数据可能删除录音；它不是扩展独立的私密存储空间。
- 此版本未复制第三方项目代码。架构参考方向来自 DeepHear 与 Shadowing Space。

## 当前限制

- 原型仅支持普通 `/watch?v=...` 视频，暂不支持直播、Shorts、广告中录制。
- 文字记录只读取当前 DOM 已加载的行，不保证完整；YouTube 改版可能影响读取。末句终点可能估算，需手动调整。导入完整字幕更可靠。
- 录音与视频通过两个媒体元素协调播放，尚非逐帧同步。首次播放、卡顿及手动拖动 YouTube 进度条可能引入偏差；练习中请使用面板的停止按钮，避免直接操作播放器。
- 这是静音整条视频音轨，尚不支持保留背景音乐并单独消除人声。
- 下载的是独立音频，不是合成视频；没有发音评分、云同步、录音历史管理。
- 已完成字幕解析自动测试与 JavaScript 语法检查；尚未完成真实 Chrome / YouTube / 麦克风端到端测试。

## 验证

运行：

```sh
node --test tests/*.test.cjs
node --check extension/content.js
node --check extension/background.js
```

真实浏览器验收：

- 授权 / 拒绝麦克风，取消授权等待后重试。
- 设置 5 秒片段，听原声、配音、自动停止、回放、依次对比。
- 在慢速下配音并回放，确认画面和音频节奏。
- 播放 / 录音时点击停止、关闭面板、切换视频，确认麦克风释放和静音状态恢复。
- 刷新页面恢复最近录音，下载文件确认可播放。
- 分别导入 SRT / VTT，验证多行台词、跳转、隐藏台词。

## 0.1.1 台词读取修复

旧版只读取点击瞬间的 DOM，文字记录未展开或正在加载就会报错。新版会尝试展开简介、打开文字记录，最多等待约 12 秒，并兼容新旧台词节点。停止、关闭面板或切换视频会取消读取。没有新增权限。

更新后需要在 `chrome://extensions` 重新加载 Echo，**再刷新 YouTube 页面**。仅重新打开面板不会更新已注入的代码。

已在视频 `suXUsAVOSnY` 的 YouTube 页面手动确认文字记录可加载，包含 152 个台词节点；台词为中英混合。字幕按钮显示 unavailable 不能单独用来断定没有文字记录。自动流程由回归测试覆盖，尚未在用户已安装的扩展中执行端到端验证。

## 0.2.0 字幕点词与录音波形

- 选择一句台词后，点击面板当前台词中的英文单词，展开音标、词性、英文释义和例句；点「朗读」听浏览器语音。支持带撇号的词和连字符词，查不到时请尝试单词原形。词卡查询会暂停视频，练习中暂不支持查词。
- 查词时仅将该单词发送至 `https://api.dictionaryapi.dev`，不发送整句、视频链接或录音。新版本增加对此域名的访问权限。释义为英文；浏览器朗读优先使用本机英文语音，具体语音可用性取决于浏览器配置。
- 录音完成或恢复最近录音后，在本机解码音频并绘制波形；橙色标出持续至少 0.4 秒的低音量区域。显示录音秒数和停顿位置，过低音量会提示检查麦克风。
- 这些是音量和停顿提示，不是发音准确度评分。没有基于波形判定“读错词”，也没有原声双波形或音素识别。逐词/逐音素错误定位需要额外的发音评测模型；当前未配置或调用此类服务。

更新后重新加载扩展，再刷新 YouTube 页面。
