# Echo · 配音与唱歌练习

把喜欢的 YouTube 对白和歌曲，变成自己的声音。支持英语、中文、日语、韩语等原文字幕的逐句配音、跟读、伴奏录唱与回听。普通配音无需后端或 API Key；可选的去原唱伴奏需要启动本机服务。

## 安装

从 GitHub 仓库选择 **Code → Download ZIP** 并解压，或使用 Git 克隆仓库。加载时选择解压目录中的 `extension/` 文件夹，不是整个仓库。

1. 在 Chrome 地址栏打开 `chrome://extensions`。
2. 打开右上角「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择本项目下的 `extension` 文件夹。
4. 打开或刷新一个 YouTube 视频播放页，点击工具栏的 Echo 插件图标打开面板（可先在扩展程序菜单里固定图标）。

修改代码后，在扩展程序页面点重新加载，再刷新 YouTube 页面。

### 可选：一键安装并启动伴奏服务

普通配音、跟读、录音和回放只需要 Echo 扩展。「生成伴奏」还需要在运行 Chrome 的同一台电脑上启动本机服务；安装扩展不会自动安装这些依赖。

打开终端，进入解压或克隆后的项目根目录，运行：

```bash
bash start-karaoke.sh
```

首次会检查 Python 3.10–3.12、FFmpeg 和 JS 运行时，创建项目独立环境并安装依赖，然后启动服务。以后仍运行同一命令，会复用已安装环境；安装失败后可修复错误并重新运行。首次安装需联网，依赖可能占约 1–2 GB；约 80 MB 的分离模型在首次生成伴奏时下载。

- **Linux x86_64**：支持；缺少系统组件时通过 apt 安装，可能要求管理员密码。其他发行版需自行配置 Python / FFmpeg。
- **macOS Intel / Apple 芯片**：已提供脚本安装路径，尚待实机验证；缺少系统组件时需要已安装 Homebrew。
- **Windows**：当前脚本暂不支持。

保持终端开启，按 `Ctrl+C` 停止。回到插件切换「唱歌曲 · 保留伴奏」，查看服务状态；已打开面板时可点击「重新检测」。连接成功后生成伴奏，再试听和录唱。未连接时会展开启动说明。服务只监听 `127.0.0.1:8765`；已有的浏览器伴奏缓存和录音回放不要求服务在线。

完整配置、手动安装及限制见 [伴奏安装与使用](karaoke/README.md)。

## 使用

顶部按活动切换「说对白 · 配音跟读」和「唱歌曲 · 保留伴奏」。说对白适用于访谈、影视、动漫等，直接录制麦克风；唱歌曲复用本机伴奏生成和混音录唱。切回说对白或切换视频会关闭伴奏。内容语言在折叠的「练习设置」中选择，默认根据文本建议，可手动更正。

1. 在面板底部搜索视频，或直接打开喜欢的视频。优先选择带目标语言字幕或时间轴歌词的视频。
2. 点击「读取台词」，插件会尝试展开视频简介、打开文字记录，并等待台词加载；也可以导入 SRT / VTT 字幕。
3. 选择一句台词，或在视频播放时标记起点、终点。每段最多 10 分钟，可选 0.75×、1×、1.25×。
4. 点击「听原声」，再点击「开始配音」，首次使用需允许麦克风权限。
5. 配音时视频静音并继续播放，到终点自动停止，也可手动停止。
6. 点击「我的配音 + 画面」随视频回放，或点击「原声 / 配音」依次听两种版本。
7. 可隐藏台词练习脱稿，也可下载 WebM 录音。

回放使用**录制时**的起止点与速度，不受之后选中的字幕片段影响。每句保留最近 3 次录音；第 4 次会替换该句最早的一次。展开「录音 → 录音版本」可选择旧版本、下载或删除，并可撤销最近一次删除。

## 数据与权限

- 仅在 `https://www.youtube.com/*` 注入内容脚本，没有全站读取权限。点词查询使用 Free Dictionary API。
- 麦克风由浏览器按需授权。停止录音后释放麦克风。
- 录音存入 YouTube 页面来源下的 IndexedDB，没有音频上传接口。清理网站数据可能删除录音；它不是扩展独立的私密存储空间。
- 此版本未复制第三方项目代码。架构参考方向来自 DeepHear 与 Shadowing Space。

## 当前限制

- 原型仅支持普通 `/watch?v=...` 视频，暂不支持直播、Shorts、广告中录制。
- 文字记录只读取当前 DOM 已加载的行，不保证完整；YouTube 改版可能影响读取。末句终点可能估算，需手动调整。导入完整字幕更可靠。
- 录音与视频通过两个媒体元素协调播放，尚非逐帧同步。首次播放、卡顿及手动拖动 YouTube 进度条可能引入偏差；练习中请使用面板的停止按钮，避免直接操作播放器。
- 普通配音静音整条视频音轨；可选的本机去原唱功能见 [伴奏安装与使用](karaoke/README.md)。
- 下载的是独立音频，不是合成视频；没有发音评分或云同步；录音版本与历史保存在本机浏览器中。
- 已完成字幕解析自动测试与 JavaScript 语法检查；尚未完成真实 Chrome / YouTube / 麦克风端到端测试。

## 0.1.1 台词读取修复

旧版只读取点击瞬间的 DOM，文字记录未展开或正在加载就会报错。新版会尝试展开简介、打开文字记录，最多等待约 12 秒，并兼容新旧台词节点。停止、关闭面板或切换视频会取消读取。没有新增权限。

更新后需要在 `chrome://extensions` 重新加载 Echo，**再刷新 YouTube 页面**。仅重新打开面板不会更新已注入的代码。

已在视频 `suXUsAVOSnY` 的 YouTube 页面手动确认文字记录可加载，包含 152 个台词节点；台词为中英混合。字幕按钮显示 unavailable 不能单独用来断定没有文字记录。自动流程由回归测试覆盖，尚未在用户已安装的扩展中执行端到端验证。

## 0.2.0 字幕点词与录音波形

- 选择一句台词后，点击面板当前台词中的英文单词，展开音标、词性、英文释义和例句；点「朗读」听浏览器语音。支持带撇号的词和连字符词，查不到时请尝试单词原形。词卡查询会暂停视频，练习中暂不支持查词。
- 查词时仅将该单词发送至 `https://api.dictionaryapi.dev`，不发送整句、视频链接或录音。新版本增加对此域名的访问权限。释义为英文；浏览器朗读优先使用本机英文语音，具体语音可用性取决于浏览器配置。
- 录音完成或恢复最近录音后，在本机解码音频并绘制波形；橙色标出持续至少 0.4 秒的低音量区域。显示录音秒数和停顿位置，过低音量会提示检查麦克风。
- 这些是音量和停顿提示，不是发音准确度评分。没有基于波形判定“读错词”，也没有原声双波形或音素识别。逐词/逐音素错误定位需要额外的发音评测模型；当前未配置或调用此类服务。

更新后重新加载扩展，再刷新 YouTube 页面。

## 0.3.0 逐句练习优化

- **中英分开**：当前句默认突出英文，勾选「显示中文参考」展开中文。混合台词按字符类型拆分，不是自动翻译；中文部分内的英文术语可能被归入英文行。可展开「查看未拆分台词」核对原文。台词列表默认展示英文；「隐藏台词」也会隐藏中文和原文。
- **单句循环**：选定片段后，点击「单句循环」，可选 3 次、5 次或持续循环，每次间隔 0.6 秒；点「停止」随时结束。
- **自动跟读**：先检查麦克风权限，依次听原声、准备倒计时、静音配音、回放配音。默认练一句；勾选「完成回放后，自动练下一句」可连续练习。每个视频仍只保存最近一次录音，请下载需要保留的版本。没有发音评分或自动判错。
- **边界微调**：起点和终点各有 ±0.2 秒按钮，限制在视频时长内，并保持至少 0.1 秒片段。修改在本次页面会话中保留，切换句子再回来仍有效，重新读取字幕或刷新后恢复。直接输入时间也会更新当前句。
- **修复**：自动读取字幕完成后，先解除读取状态再选中第一句，避免台词已加载但仍停留在手动片段。

本轮自动测试覆盖混合字幕拆分、边界限制、循环次数、取消倒计时、连续跟读顺序及录音失败后不播放旧录音。尚未验证真实 Chrome 的完整麦克风流程。安装更新方式同前：重新加载 Echo 后刷新视频页。

## 0.4.0 面板布局

面板改为三个页签：

- **练习**：当前台词、原声、配音、回放，以及循环/自动跟读入口。速度、循环次数和倒计时收进「练习设置」；时间输入及微调收进「片段与边界」，默认折叠并显示当前参数摘要。
- **台词**：读取、导入字幕及台词列表，选择一句即回到练习；视频搜索单独折叠。
- **录音**：回放、原声对比、波形和下载。没有录音时显示提示，不占练习页空间。

停止按钮在任务运行时出现在底部状态栏，切换页签后仍能停止。页签支持左右方向键和 Home / End。切换页签不会中断录音；关闭整个面板仍会停止任务。词卡仅在点词后出现。没有新增权限。

已检查独立 HTML 预览布局及页签；完整扩展的麦克风流程仍需在 Chrome 上实测。重新加载扩展并刷新 YouTube 页面以更新。

## 0.5.0 练习进度与录音历史

- 自动保存每个视频的台词、练习句子、修改后的片段边界、速度和字幕显示偏好。重新打开同一视频时自动恢复，不自动播放或启动麦克风，仅在底部提示已恢复位置。
- 每句独立保留最近 3 次录音；微调边界不会把同一句当成新句子。手动片段按起止时间分组。每个录音保留录制时的边界和速度，选择旧录音可直接随画面回放、比较和下载。
- 「录音版本」放在原有录音页的折叠区，默认只列当前句；也可切换为当前视频全部录音。练习页不增加常驻按钮。
- 支持删除所选录音和撤销最近一次删除。撤销仅在当前页面、当前视频内有效，开始新录音会清除撤销入口；超过三次时自动替换的最旧版本不可撤销，请提前下载。
- 升级会将旧版最近一次录音迁移到新录音库；旧版没有保存过台词/进度，因此首次升级无法恢复此前的台词位置。
- 数据仍存于 YouTube 来源的本机 IndexedDB，没有云同步或音频上传，也没有新增权限。清除网站数据会移除进度和录音。

开发测试使用 `npm ci` 后运行 `npm test`；fake-indexeddb 仅用于测试数据库迁移、版本保留、删除恢复和会话存储。插件依旧无需安装依赖或构建，直接加载 `extension/`。

## 0.6.0 从头连续播放配音

在「录音」页点击「从头连播配音」，自动按当前视频的时间顺序，播放每个已录句子/手动片段的最新录音，并随原画面回放。未录部分直接跳过，同一句的旧版本不重复播放；每段仍使用录制时的起止点与速度。即使当前选中句没有录音，只要视频里有已保存录音也可以启动连播。

底部显示第几段/总段数，点击「停止」、关闭面板或切换视频可取消。此功能连续播放已录片段，不是从视频 0 秒起保留所有空白间隔的整片配音合成，也不会生成合成音频/视频文件。沿用现有回放实现，没有改变音频播放方式。

测试覆盖每句取最新版本、按时间排序、未录句状态下启动连播、停止后不播放下一段，以及播放完恢复视频静音状态。真实 Chrome 播放流程仍需实测。

## 0.7.0 更直接地查找与切换录音

「录音」页默认展示当前视频全部已录句子，按视频时间排序，列表中每句只显示一行（最新版本）。点击句子立即随画面播放，不再需要先展开版本、选择范围、选录音、再点回放。

- 当前录音卡片显示对应台词、片段时间和回放/原声对比按钮。
- 同句有多个版本时，卡片下直接显示版本按钮，点一下切换并播放；普通单段回放期间可直接切到别句/别版本，再点正在播放的同一录音可停止。录音和自动练习期间仍禁止切换，避免打断。
- 输入关键词、句子编号或 `分:秒` 时间可筛选列表；搜索不会改变练习位置或影响整段连播。
- 波形、下载、删除和撤销放入「所选录音详情」，默认折叠。主界面聚焦句子和版本，不新增页面。
- 重复选中同一个录音不再重新创建音频 URL 和计算波形。沿用原来的音频回放方式。

测试覆盖句子一键回放、旧版本一键切换、关键词查找以及此前的连播、进度恢复、录音迁移和删除撤销。真实 Chrome 播放体验仍需实测。


## 跟随字幕与上下句预告

练习页默认勾选「字幕跟随视频」。读取台词或导入带时间轴的 SRT / VTT 后，播放原声、录音、整首录唱及回放时，字幕按视频时间自动翻句：中间突出当前句，上下淡化显示上一句与下一句，并在换句时淡入。前奏和句间空白会提前显示即将开始的台词及倒计时；拖动进度后重新对齐。

唱歌与常规配音都使用同一套显示逻辑。字幕跟随只改变显示，不修改当前练习句、录音起止时间、录音版本或保存进度。可取消「字幕跟随视频」固定显示选中的练习句；「脱稿练习」隐藏当前句、上下句预告和译文。系统启用减少动态效果时不播放淡入动画。

生成伴奏不会生成歌词；没有时间轴字幕时需先读取视频台词或导入字幕文件。同步准确度取决于字幕本身的时间轴。

## 0.8.0 多语言原文与中文歌曲

Echo 从英语练习扩展为多语言对白与歌曲练习。语言设置与活动模式分开：同一套选句、录音、回放和版本历史用于各语言；歌曲仍使用现有伴奏服务，不按语言重复生成模型或增加新页面。

- 默认保留字幕完整原文，中文歌词不再被当成译文隐藏，日语汉字不再拆入中文区域，韩语及混合英文歌词也完整保留。当前句、上下句、台词列表、录音检索和录音卡片共用显示规则。
- 「练习设置」提供自动建议、英语、中文、日语、韩语、其他/不确定。建议只根据字幕文字，不识别声音，不区分汉字独占的日语与中文，也不自动区分中文方言；可随时手动更正。
- 原文、参考文本在显示层独立。当前仍读取/导入原有 SRT/VTT 时间轴；没有自动生成翻译或歌词。已有英中混排字幕可显式选择「英中混排分开显示」，仅英语内容启用，不对日文/韩文做字符拆分。旧英语练习保留原有拆分偏好，旧中文练习保持原文。
- 有参考文本时才显示「显示参考」选项，不展示空翻译控件。英语保留词典/音标和朗读；中文、日语、韩语尚未接入查词、拼音、假名、罗马字和发音评分，不会把这些语言送到英文词典。
- 语言与台词格式按视频保存，刷新恢复；新视频回到自动建议和完整原文。原有录音、伴奏缓存和稳定句子标识不变，没有新增权限或模型下载。

### 中文歌曲使用路径

1. 打开有时间轴歌词的视频，读取台词或导入 SRT/VTT。确认中文歌词完整显示；需要时在折叠设置里将内容语言指定为中文。
2. 选择「唱歌曲 · 保留伴奏」，生成整首或当前片段伴奏。生成伴奏不依赖字幕语言，也不会生成歌词。
3. 试听、调音量、戴耳机录唱；歌词随时间翻句。录完原地回听、重录或下载，录音历史继续保留。

日语、韩语按同一流程使用，优先提供相应原文字幕。字幕时间轴和去原唱音质仍取决于素材；本轮没有重新运行模型分离，也没有做真实麦克风跨语言人工录唱验收。

验证：59 项 JavaScript 测试及 9 项本机服务测试通过，包含中/日/韩原文不丢字、录唱模式字幕跟随、设置恢复和旧会话兼容。

## 0.8.1 伴奏生成无反馈提示

连接/生成失败会保留按钮旁的具体错误，不再被普通说明覆盖；生成时按钮显示「正在生成伴奏」。超过整首 10 分钟限制时，在按钮旁及底部提示改用当前片段。

如果点击生成后没有进度，先看按钮下方错误。伴奏服务运行在使用 Chrome 的同一台电脑上：拉取 GitHub 代码不会同步被忽略的 `.venv`、模型缓存或启动中的服务。在项目根目录运行 `bash start-karaoke.sh` 安装并启动，保持终端打开，再点击「重新检测」。详情见 [伴奏安装说明](karaoke/README.md)。更新插件后仍需重新加载扩展、刷新 YouTube 页面。


## 0.8.2 稳定性与交互整理

- 切换视频导致录音停止时，已录到的音频仍保存到原视频；保存完成后再提示成功。普通配音遇到缓冲也暂停录音，恢复播放时继续，减少插入静音造成的错位。
- 字幕导入支持取消，并忽略切换视频前尚未完成的读取。微调录音边界不再改写原字幕时间轴。字幕解析拒绝无效时间戳，文字记录的结束时间计算避免反复扫描后续全部台词。
- 演唱与手动配音分别保留最近三个版本；已有演唱记录自动迁移，不删除音频。波形分析仅在展开「所选录音详情」时运行，减少长录音后台解码的内存占用。
- 生成错误集中在按钮下方。检测到旧版伴奏服务时提示重启；重复启动遇到端口占用也给出操作说明。安装脚本可修复未完成的 pip 安装。

更新时重新加载扩展并刷新 YouTube 页面；为避免数据库升级被旧标签页阻挡，请刷新其他已打开的 YouTube 标签页。伴奏服务需在旧终端 Ctrl+C 后重新运行 `./start-karaoke.sh`。本轮保留整段处理、最长 10 分钟，不启用分段拼接。


## 0.9.0 面向练习流程的界面整理

- **唱歌主区**：录唱范围、听原曲、开始整首 / 片段录唱、回听演唱放在顶部。最新演唱的重录、下载直接显示；不再藏在伴奏设置里。尚无伴奏时，点击录唱会展开准备设置，不自动分离或请求麦克风。
- **伴奏设置**：默认折叠，集中管理生成、试听、音量和本机服务。生成开始后收起设置，主区持续显示进度；停止按钮始终保留在底部。缺少服务时的说明按需展开。
- **逐句练习**：配音模式直接显示录音、原声、回放和自动跟读；唱歌模式收进「逐句练唱（可选）」。在歌词列表选择一句后自动展开逐句练唱，整首范围保持原选择。
- **字幕与设置**：有台词后自动收起读取 / 导入入口；台词页新增搜索，过滤后仍选择原来的时间点。语言、速度、跟读参数及边界保持折叠；上一句 / 下一句在边界处禁用。
- **录音页**：统一叫「我的录音」，容纳配音与演唱；仍保留直接点播、版本切换、搜索、删除撤销和折叠的波形详情。录制期间收起准备项与设置，突出字幕 / 歌词，底部按钮显示「结束录音」。

更新方式：重新加载扩展并刷新 YouTube 页面。此轮界面调整不要求重装本机伴奏依赖。


## 0.9.1 伴奏音量

伴奏音量默认 100%，范围 0–200%，显示当前百分比并按视频保存。滑块使用独立样式，移除文本输入框的内边距；试听时可实时调整，试听与录唱使用相同增益。已保存的演唱音频不随滑块改变，需重新录唱才会使用新的伴奏音量。


## 0.9.2 自定义面板尺寸

拖动面板左下角的 ⤢ 手柄，可同时调整宽度与高度；双击手柄恢复默认尺寸。也可用 Tab 聚焦手柄，通过方向键微调，Shift + 方向键加快，Home 恢复默认。尺寸在当前浏览器的 YouTube 站点本地保存，刷新或切换视频后继续使用；清除站点数据会重置。缩小浏览器窗口时面板自动限制在可见区域，放大窗口后恢复偏好尺寸。


## 0.9.3 合并录唱入口

主区只保留一个录唱按钮：当前范围与速度已有演唱录音时显示「再录一次」，否则显示「开始整首 / 片段录唱」。两者都按当前选择录制，并保留旧版本。结果区移除重复的「重新录唱」。要复用旧版本的范围与速度，可在「录音 → 所选录音详情」点击「使用此版范围练唱」，回到主区后再开始录制。
